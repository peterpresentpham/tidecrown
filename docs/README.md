## Cách duy trì

- Luật và số liệu thực thi nằm trong code (`src/data`, `src/game`); tài liệu mô tả và giải thích, không phải nguồn thứ hai.
- Đổi luật thì cập nhật đúng tài liệu chủ đề; không tạo bản hướng dẫn theo phiên bản song song.
- Không lưu báo cáo theo từng đợt hay số đo của luật cũ. Kết quả đo mới ghi ngắn trong [roadmap.md](roadmap.md) kèm lệnh tái lập.
- Prettier bỏ qua `docs/` để giữ bảng markdown; giữ dòng ngắn và bảng thẳng hàng khi sửa tay.
